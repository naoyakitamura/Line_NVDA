# LINE読み上げ補助

Windowsデスクトップ版LINEをNVDAで操作する非公式アドオンです。作者：NAOYA。

## ダウンロード

[Releases](https://github.com/naoyakitamura/Line_NVDA/releases)に、NVDA 2025.3jp用・2026.2jp用のファイルを分けて掲載しています。現在は共通の機能・バイナリです。説明書とソースコードは各リリースの `trial.zip` に含まれます。

Windows x64と、対応する64ビットLINEが必要です。対象LINEは26.4.2.3957／26.3.0.3916の確認済み実行ファイルに限定しています。NVDA 2025.3jp本体での実操作は未確認の試用版です。

## 更新通知

リリース公開時、両版のファイルとソース付きZIPのチェックサムを確認してから、Discordサーバー「PC版Line読み上げアドオンテスターズ」の「アップデート情報」に変更内容と各ダウンロードリンクを自動通知します。2026年9月30日のv2.29.1公開で動作を確認しました。

[アップデート情報（サーバー参加者向け）](https://discord.com/channels/1554836947120300153/1554837047624204339)
